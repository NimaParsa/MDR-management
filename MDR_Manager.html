How it works

1. Click New transmittal to create a transmittal record.
2. Filter/search and select the documents to include from the MDR, entering a revision for each.
3. Fill in the transmittal metadata (number, date, recipient, purpose, etc.).
4. Choose which sections to include in the printed form.
5. Use Print preview to review, then print or save as PDF.
